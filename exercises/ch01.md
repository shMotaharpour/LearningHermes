# Exercise 1 — Foundations

1. Run `hermes doctor` and paste the output into a note. Fix anything it flags.
2. Run `hermes model`, find your current provider and model, then switch to a cheaper model with `/model <name>` (session-only). Switch back with `/model <orig>` after one exchange.
3. Create a model alias from your shell:
   ```bash
   hermes config set model.aliases.fast <provider/fast-model>
   ```
   Then use `/model fast` in a chat.
4. Create your first session in Telegram (or CLI): `/new`, then `/title foundations-practice`. Verify with `/sessions`.
5. Run `/status` and identify: your model, session name, and token usage.

Deliverable: a short note (5 lines) describing what `hermes doctor` reported and what you changed.
