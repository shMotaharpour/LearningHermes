# تمرین ۰۵ — Toolها و قابلیت‌ها

## Objective

تمرین دیسیپلین تطبیق قابلیت: scope ی toolset برای هر کار، پیمودن نردبان وب، و اجرای مسیرهای
سند/vision/رسانه.

## Tasks

1. **فهرست.** `hermes tools list` — کدام toolsetها فعال‌اند؟ یکی را که این هفته لازم
   ندارید disable کنید؛ اثر prompt-size را ثبت کنید (`hermes prompt-size`).
2. **اجرای scope‌شده.** یک سؤال، دو بار: یک‌بار `-t web`، یک‌بار با همهٔ toolsetها.
   جواب‌ها، latency و انحراف‌های wrong-tool را در transcript مقایسه کنید.
3. **نردبان escalation.** یک سؤال پژوهشی واقعی بردارید:
   - `web_search` → snippetها و URLها را ثبت کنید.
   - `web_extract` روی URL اول → ببینید markdown تمیز چه چیزی اضافه داشت.
   - یک صفحهٔ JS-سنگین پیدا کنید و بگذارید browser بخواندش — تنها پله‌ای که آنجا کار می‌کند.
4. **استخراج سند.** یک PDF واقعی به agent بدهید. خلاصهٔ ساختاریافته با ارجاع صفحه بخواهید.
   بعد یک PDF ی اسکن‌شده را امتحان کنید — شکست تصویری را ببینید، دوباره با vision اجرا کنید.
5. **Vision.** یک اسکرین‌شات بفرستید (paste در CLI یا عکس در Telegram) و سؤالی بپرسید که
   فقط از پیکسل‌ها جواب دارد (مثلاً «بنر خطا چه می‌گوید؟»).
6. **وضعیت computer use.** `hermes computer-use status` — اگر درایور نصب است،
   `hermes computer-use doctor` را اجرا و ماتریس چک‌ها را بخوانید. هنوز دسکتاپ را نرانید؛
   آن با فصل امنیت می‌آید.

## Verification checklist

- [ ] یک toolset غیرفعال و تفاوت prompt-size اندازه‌گیری شد.
- [ ] نردبان escalation با یک سؤال واقعی نمایش داده شد (هر سه پله).
- [ ] PDF ی متن‌لایه با ارجاع extract شد؛ PDF ی اسکن‌شده درست به vision رفت.
- [ ] یک سؤال vision جواب گرفت که از متن به‌تنهایی ناممکن بود.
