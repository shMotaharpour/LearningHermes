=== Hermes Agent — docs/research/hermes/llms.txt (in-repo snapshot, official docs index) ===

"A terminal-native autonomous coding and task agent with persistent memory, agent-created

=== Interpretation notes (chapter-draft material; prose in README.md cites this file) ===

1. Five compared tools fall into two families:
   - Coding-agent CLIs (Claude Code, Codex CLI, OpenCode, Gemini CLI): terminal-first,
     repo-centric, best at code tasks. Claude Code extends furthest (IDE + desktop + web).
   - Gateway agents (Hermes, OpenClaw): a resident gateway process bridges messaging
     platforms to the agent core; sessions, cron, webhooks are first-class.
2. Model access: vendor CLIs are built around their maker's models (Claude/GPT/Gemini);
   OpenCode and Hermes are provider-agnostic (any provider / OpenAI-compatible endpoint);
   Hermes adds provider fallback chains and credential pools (Chapter 02).
3. Automation: Hermes exposes cron, webhooks, hooks, and multi-agent orchestration as
   subcommands (verified: hermes --help in cli-evidence-2026-09-07.txt); the coding CLIs'
   docs position automation as CI/CD integration or scheduled desktop tasks, not a
   built-in scheduler. OpenClaw has cron/webhooks listed under capabilities.
4. Identity/self-modification: agent-created skills + persistent memory + profile export
   are documented Hermes differentiators (llms.txt); coding CLIs use static instruction
   files (CLAUDE.md/AGENTS.md) maintained by the user.
